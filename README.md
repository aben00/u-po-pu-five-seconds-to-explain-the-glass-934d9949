The one sentence a house cat would say in the five seconds after sweeping a glass off the table.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This prints the cat's excuse and writes it to `entry.txt` inside the output directory (default `/output` when `MAKEFUN_OUTPUT_DIR` is unset). Node 22 or later, no dependencies, no network.
